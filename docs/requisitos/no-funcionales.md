# Requisitos no funcionales

| Código | Categoría | Descripción | Prioridad |
|--------|-----------|-------------|-----------|
| RNF-01 | Accesibilidad táctil | La separación mínima entre puntos de una lámina debe ser al menos 2.5 mm; un valor menor a este umbral debe producir una advertencia visible y accesible. | Alta |
| RNF-02 | Interoperabilidad | El archivo exportado debe ser SVG válido y estándar, conservar la orientación A4 y abrirse en aplicaciones vectoriales sin depender de la aplicación del Taller. | Media |
| RNF-03 | Usabilidad | Las advertencias de distancia deben aparecer al colocar o mover puntos y desaparecer cuando todos los pares vuelvan a cumplir el umbral mínimo. | Alta |
