# Definition of Done (DoD)

Una historia de usuario o historia técnica se considera **Hecha** cuando:

- [ ] Cumple todos sus criterios de aceptación (Gherkin).
- [ ] El código fue revisado por al menos otro integrante mediante Pull Request.
- [ ] Se probó que funciona y no rompe lo anterior.
- [ ] La documentación está actualizada.
- [ ] Si el cambio alteró el diseño original, los diagramas en `docs/diagramas/` también se actualizaron.
- [ ] El Product Owner la revisó y la aprobó.
- [ ] El Issue se movió a "Hecho" en el tablero.
